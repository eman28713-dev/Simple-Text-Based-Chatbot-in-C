# Simple-Text-Based-Chatbot-in-C

Developed a simple text-based chatbot in C using keyword matching and scoring. 
The chatbot handles greetings, name recognition, study tips, time/date queries, 
and basic topics including Software Engineering, Web Development, Databases, 
AI, and Networking.

## Features

- Keyword-based chatbot interaction
- Greeting and name recognition
- Study tips
- Current time and date
- Software Engineering information
- Web Development information
- Database and DBMS information
- AI and Machine Learning information
- Networking concepts
- Random chatbot responses
- Help and exit commands

## Technologies Used

- C Programming
- String Handling
- Functions
- Arrays
- `strstr()`
- Random Number Generation
- Time and Date Functions
- Keyword Matching
- Conditional Statements
- Loops

## How to Run

1. Download or clone the repository.
2. Open `chatbot.c` in a C compiler.
3. Compile the program.
4. Run the executable.
5. Start chatting with the bot.

## Project Purpose

This project was developed to practice C programming concepts, 
string manipulation, functions, arrays, conditional statements, 
and basic keyword-based chatbot logic.
